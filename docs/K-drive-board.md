## 1. 编制说明与映射规则

> 《F 类团队职责工作驱动板》编制说明原文本次未提供。以下映射规则是按 5W2H、SMART、SAO 的通行定义编制的**假设版本**，收到原文后按其口径调整字段名和顺序即可，内容不受影响。

### 1.1 字段映射

| 驱动板字段 | 映射规则 |
|---|---|
| **What（做什么）** | 岗位职责事项和交付物，取自对应 K 文档的任务 1—6 |
| **Why（为什么）** | 关联的业务目标（G1—G4，见 README §2）或质量目标；每条职责至少关联 1 个 |
| **Who（谁来做）** | R 负责岗位；C 协作岗位；I 知会对象（RACI） |
| **When（何时）** | 里程碑周次（T0 + Wn，见 README §3）与截止闸门 |
| **Where（在哪里）** | 工作环境 / 系统（设计工具、代码仓库、测试环境、生产环境等） |
| **How（怎么做）** | 方法、流程、规范（引用 K 文档章节） |
| **How much（做多少 / 做到什么程度）** | 工作量（人日估算）+ 衡量指标目标值 |
| **SAO 职责描述** | 每条职责写成"**主体 S（岗位）— 动作 A（可验证的动词）— 对象 O（交付物 / 系统对象）**"，编号 `K-xx-Rn` |
| **SMART 衡量口径** | S：对象 O 明确；M：指标 + 公式 + 数据来源；A：标注可达成依据（基线 / 资源 / 行业标准）；R：关联 G 编号或质量目标；T：截止节点 |
| **输入 / 输出** | 输入 = 开始工作所需的上游交付物；输出 = 交给下游的交付物（见 §3 交接矩阵） |
| **前置 / 后置条件** | 前置 = 允许开工的就绪状态（闸门）；后置 = 完成后必须达到的状态与交接动作 |
| **使用系统 / 软硬件工具** | 完成职责所用的平台、软件、硬件、测试设备 |

### 1.2 目标与质量目标编号
- **G1** 有效预约演示线索 ≥ 30 条 / 月（上线后 90 天内）
- **G2** 白皮书下载 ≥ 100 次 / 月
- **G3** 首页跳出率 ≤ 55%
- **G4** 首页移动端 LCP ≤ 2.5 s（P75）
- **Q1** 设计还原度 ≥ 95%；**Q2** 无障碍 WCAG 2.1 AA；**Q3** 零阻断 / 严重缺陷上线；**Q4** 页面可用性 99.9%；**Q5** 安全高危漏洞 = 0
