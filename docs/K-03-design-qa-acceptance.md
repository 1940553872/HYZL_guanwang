## 6. 还原度度量

**公式**：还原度 = 通过项数 / 总走查项数 × 100%

**统计口径**
1. **总走查项**：§1 走查记录表中所有项，按"页面 × 断点"计数，同一走查项在 3 个断点分别计 3 项；§3 兼容走查以"页面 × 浏览器"为单位单独统计兼容通过率，不计入还原度。
2. **通过**：实测值落在 §1 容差内；"一般"级偏差判为不通过。
3. **不适用项**（如移动端不存在的悬停态）从分母剔除，并在报告中列出。
4. **复验**：整改后以最新一轮结果重新计算，报告同时保留首轮数据。
5. **分页面统计**：除全站还原度外，P-01、P-03、P-12、P-17 四个关键页面单独计算，每页均需 ≥ 95%。

**报告输出**：全站还原度、关键页面还原度、各类别通过率（布局 / 字体 / 颜色 / 间距 / 图标 / 图片 / 交互状态 / 动效）、兼容通过率、问题级别分布。
