## 2. 项目基线（所有文档共用）

| 项 | 内容 |
|---|---|
| 项目名称 | 华云智联官网 V2.0 改版（huayunzhilian.cn） |
| 企业定位 | 工业人工智能 B 端企业，旗舰产品 **SpatiGo™ 空间群弈™** 智能体集群（质量之弈 / 运维之弈 / 安全之弈 / 具身之弈） |
| 改版目标 | 从"白皮书文档派"升级为"**B 端权威 + 强视觉**"：权威性保持，视觉表达和转化能力补齐 |
| 业务目标（建议值，需市场部确认基线） | G1 上线后 90 天内，有效"预约现场演示"线索 ≥ 30 条/月；G2 白皮书下载 ≥ 100 次/月；G3 首页跳出率 ≤ 55%；G4 首页移动端 LCP ≤ 2.5 s（P75） |
| 站点范围 | 中文站（P0）、英文站（P1）；PC + 移动响应式；内容管理后台；线索表单；白皮书下载；站内搜索；访问统计 |
| 不在范围 | SpatiGo™ 在线试用 Demo（后续独立子站）、电商与支付、会员体系 |
| 流量假设 | 日均 PV 3,000—10,000；发布会 / 展会峰值按 10 倍估算；页面经 CDN 缓存；动态接口峰值 50 QPS，压测目标 200 QPS |
| 部署区域 | 中国内地（需 ICP 备案、公安备案）；英文站同源部署，海外访问经 CDN 加速 |
| 终端范围 | 响应式：PC（≥1280）、平板（768—1279）、移动（<768）；含微信内置浏览器 |

## 4. 统一约定
- **需求编号**：`REQ-<模块>-<序号>`，如 `REQ-LEAD-01`；**缺陷级别**：阻断 / 严重 / 一般 / 建议（K-03、K-06 共用）。
- **页面编号**：`P-<序号>`，定义见 [K-02 §2](./K-02-ux-ia-usability.md)，各文档统一引用。
- **断点**：`xs <640`、`sm ≥640`、`md ≥768`、`lg ≥1024`、`xl ≥1280`、`2xl ≥1440`（设计基准宽 1440 / 390）。
- **目标浏览器**：见 [K-04 §4](./K-04-frontend.md)，K-03、K-06 共用。
- **待确认事项**用"【待确认】"标注，评审时逐条关闭。
