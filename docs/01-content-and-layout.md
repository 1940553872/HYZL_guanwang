## 1. 现状与目标

| 维度 | 现状（据 research/05 抓取） | 目标 |
|---|---|---|
| 内容资产 | 头部级：国际标准主编、100+ 工业集团客户、SpatiGo™ 四子产品、具身智能场景、量化指标 | 保持，并**可视化、模块化** |
| 首页 | 无 Hero，主体内容缺失 | 一屏讲清"是谁、做什么、凭什么信" |
| 关于页 | 标准履历长文 | 卡片化：使命、标准墙、历程、资质 |
| 产品页 | 技术规格书（参数表、标准号堆砌） | "价值 → 能力 → 证据 → 规格（折叠 / PDF）"四层 |
| 配图 | 几乎为零 | 实拍现场 + 数字孪生 + 架构图三类主视觉 |
| 品牌色 / 字体 | 默认政企站白底黑字 | 建立"近黑 + 工业橙"色谱与设计 Token |
| 文案 | 工程第三人称 | 客户视角第二人称 + 证据脚注 |

**定位坐标**：B 端权威性已经拉满，缺的是视觉表达。改版路径是"**纵轴不动，横轴右移**"，向 NVIDIA、华为云盘古所在的"B 端权威 + 强视觉"区靠拢（见 research/05 §4）。

## 2. 内容呈现策略："1 + 3" 混合范式

沿用 research/05 的结论，并与调研中的工业软件范式合并：

| 层 | 范式 | 承担任务 | 参考（research 01—03） |
|---|---|---|---|
| **1 · Hero** | 大陈述派 | 立权威：使命句 + 三枚大数字 + 双 CTA | Anthropic、OpenAI 大字首屏；Microsoft AI 双 CTA |
| **3a · 信任带** | 工业软件"证据型内容" | 标准墙 + 客户 Logo 墙 | 西门子、Autodesk 客户背书；Anthropic 把信任内容放进一级导航 |
| **3b · 产品矩阵** | 产品陈列派 | SpatiGo™ 四子产品卡 + 分层架构图 | MiniMax 产品线色卡、华为盘古分层架构 |
| **3c · 现场证据** | 电影事件派 | 深色全屏实拍：油田 UAV 巡检、UGV 作业、数字孪生大屏 | NVIDIA 暗场、西门子"实景 + 数字孪生叠加" |

**不采用对话框派**：工业客户来官网是为了核实"你在现场跑过没有、有没有标准背书"，不是来聊天（research/05 §2.1）。如果以后要做智能体在线体验，作为独立子站接入，主站只放入口。

### 2.1 内容转换规则（现网内容 → 新官网）

| 现网内容形态 | 转换为 | 规则 |
|---|---|---|
| 段落式标准履历 | **标准墙卡片** | 每张卡：标准号、名称、角色（主编 / 参编 / 委员）、阶段（PAR / 草案 / 发布）、年份 |
| 参数表、GB / IEC 标准号 | **"技术规格"折叠区 + PDF 下载** | 首屏不出现标准号；规格保留给招采和评标人员 |
| 客户名称列表 | **Logo 墙 + 行业筛选** | 只上墙已授权 Logo；其余写"等 100+ 工业集团" |
| "7+10+2+N" 文字描述 | **纵向分层架构图（SVG，可交互）** | 自下而上：数据基座 → 7 引擎 → 10 工业软件 → 2 约束 → N 智能体 |
| 段落中的量化指标 | **大数字 + 脚注口径** | 每个数字必须附口径、来源、日期 |
| 场景描述（长庆油田、延长石油） | **案例卡（挑战—方案—成果）+ 实拍视频** | 成果至少一项量化 |
| 第三人称工程腔 | **第二人称客户视角** | 见 §6 文案规范 |

## 5. 整体布局风格

### 5.1 风格定义：**工业极简 × 深色现场段**
- **基调**：research/04 的方向 A"理性工业极简"为全站基础，方向 C"深色数字孪生"用于 Hero、现场证据和收尾 CTA。
- **关键词**：精密、可信、现场感、克制。
- **不做**：蓝紫渐变科技风、发光大脑、机器人插画、通用图库照片、轮播 Banner 堆砌。

### 5.2 色彩策略（详细 Token 见 [K-01](./K-01-ui-visual-design.md)）

| 角色 | 色值 | 说明 |
|---|---|---|
| 墨黑（深色段背景 / 正文） | #0B0D10 | 近黑，比纯黑柔和 |
| 纸白（页面背景） | #F7F7F4 | 略暖的白 |
| 工业橙（品牌强调） | #F2611D（深底 / 装饰）/ #C2410C（浅底按钮与链接） | 区别于国内 AI 与工业软件普遍的蓝色；浅底文字必须用 #C2410C 才能满足 AA |
| 数据蓝（图表专用） | #1F5FD1 | 只用于数据可视化，与品牌色分工 |
| 安全红（错误 / 危险） | #C8281E | 只用于语义状态，不作品牌色 |

> 关于 research/05 中"工业橙 / 安全红呼应 GB 2893 安全色"的说法需要更正：GB 2893 规定的安全色是红、蓝、黄、绿四种，不含橙色；橙色作为"警示"语义见于 ANSI Z535 等标准。因此"工业橙"的依据应表述为"工业现场警示色联想 + 竞品色彩区隔"，红色只保留给错误和危险状态，以免与语义色冲突。

### 5.3 版式
- **栅格**：12 列，容器最大宽 1280px，栏间距 24px；平板 8 列，移动 4 列。
- **留白**：区块上下间距 PC 128px、移动 64px，用"大留白 + 少元素"表达权威。
- **字体**：中文 HarmonyOS Sans SC（或思源黑体），西文和数字 Inter，参数与代码 JetBrains Mono；全部自托管并按需子集化。
- **组件形态**：小圆角（按钮和卡片 4px），1px 描边，几乎不用阴影。

### 5.4 配图体系（三类主视觉 + 一类辅助）

| 类型 | 用途 | 规范 |
|---|---|---|
| ① 现场实拍 | Hero、现场证据段、案例 | UAV / UGV 作业、油田、化工装置；统一调色（压暗、降饱和、保留橙色高光）；必须经过涉密与版权审查 |
| ② 数字孪生 / 系统界面 | 产品页、技术段 | 真实系统截图或大屏录屏；敏感数据脱敏；外加统一的设备外框 |
| ③ 架构图 / 流程图 | 技术架构、方案 | SVG 矢量；统一线宽 1.5px，配色只用墨黑、灰阶和工业橙 |
| ④ 抽象纹理（辅助） | 新闻、资源封面 | 由点云、网格、等高线生成的统一封面模板，按栏目换主色明度 |

### 5.5 动效
- 克制：区块滚动渐显（位移 16px、时长 400ms）；卡片悬停上浮 2px；大数字首次进入视口时计数一次。
- Hero 视频：静音自动播放、可暂停；系统开启"减少动态效果"时改为静态海报。
- 架构图：点击或悬停展开，有键盘可达的等效操作。

## 6. 文案规范

### 6.1 语态改造（承接 research/05 §3.4）

| 现状 | 改为 |
|---|---|
| "公司提供……""应支持……" | "让您的油田巡检从 8 人班组降到 1 人监管"【待确认数据】 |
| "融合 IEC 61131-3 FBD / SFC / ST" | "不改您现有的 PLC / DCS，智能体直接读懂控制逻辑" |
| "增强后数据推荐准确度高于 95%" | "1.3B 小模型跑在您的工控机上，推荐准确度 95%+¹" |
| "满足等保 2.0 二级" | "私有化部署，数据不出厂网" |

### 6.2 结构规则
- 首屏 H1 ≤ 12 字；副标 ≤ 2 行（约 60 字）。
- 每个区块：**标题（价值）→ 一句说明（怎么做到）→ 证据（数字 / 案例 / 标准）→ 行动**。
- CTA 用"具体动词 + 具体对象"：预约现场演示 / 下载《工业智能体技术白皮书》/ 查看长庆油田案例；不用"了解更多"兜底。
- 专业术语首次出现时给一句白话解释（如 HITL：关键决策由人确认）。

### 6.3 合规红线（《广告法》《反不正当竞争法》）
- 不使用"第一、最、顶级、国家级、唯一"等用语，除非附权威出处和统计口径，例如"据 XX 统计，截至 XXXX 年 XX 月……"。
- 标准相关表述要区分"主编 / 牵头 / 参编"与"PAR / 草案 / 已发布"，不把在研项目写成已发布标准。
- 客户 Logo、客户名称、客户评价都需要书面授权；未授权的只写行业，如"某大型石油企业"。
- 所有量化指标附脚注口径。

## 7. 与调研结论的对应

| 调研结论 | 在本方案中的落地 |
|---|---|
| 国外 AI"去科技化"、避开科技蓝（research/01 §5.1） | 工业橙 + 墨黑，不用蓝紫渐变 |
| 工业软件"可信度"核心、数字孪生母题（research/02 §7） | 标准墙、Logo 墙、现场证据段、数字孪生截图 |
| 极简导航 vs Mega Menu（research/03 §1.3） | 6 项一级导航 + 分组下拉，不上 Mega Menu |
| 具体 CTA、量化案例（research/03 §5） | 预约现场演示 / 下载白皮书；案例采用"挑战—方案—成果" |
| 深色首屏 + 浅色正文双模式（research/02 §5.1） | 深—浅交替的首页节奏 |
