### 1.3 索引归纳
1. **两种导航哲学**
   - **极简导航（4—6 项）**：Anthropic、xAI、DeepMind、Mistral。前提是业务聚焦，把复杂产品分流到独立产品站（claude.com、chatgpt.com）。
   - **Mega Menu（7—10 项 + 多级下拉）**：云厂商与工业软件巨头，产品线数十到上百个，必须靠"分类 + A-Z + 行业 + 角色"多维索引。
2. **"企业站 / 产品站 / 开发者站"分离**是 AI 头部的普遍做法：Anthropic（anthropic.com / claude.com / platform.claude.com）、智谱（zhipuai.cn / bigmodel.cn / z.ai）、Kimi（moonshot / kimi.com）【实测 / 公开】。
3. **长页面使用页内锚点子导航**（Microsoft AI 实测有 9 个锚点），建议吸顶，适合解决方案页和行业页。
4. **转化入口固定在导航右侧**：AI 公司用 "Try / Download / Log in"，工业软件用 "Free Trial / Buy / Contact Sales / Request Demo"，国内云厂商用"控制台 / 免费试用 / 登录注册"。
5. **超级页脚**是信息架构的第二层：Anthropic 页脚分 Products、Models、Solutions、Claude Platform、Resources、Programs、Help and security、Company、Terms and policies 共 9 组【实测】；工业软件页脚通常还有全球站点/语言、ICP 备案（国内）、合规与隐私、投资者关系。
6. **全球化索引**：金蝶 2025 年改版按访客 IP 自动跳转本地站，并支持语言切换【公开】；国外巨头普遍有 Region/Language 选择器。

## 2. 首页内容编排（区块顺序）

### 2.1 实测样本

**Anthropic 首页【实测】**
1. 顶部导航（Research / Policy / Commitments / Learn / News + Try Claude）
2. 首屏：H1 "AI research and products that put safety at the frontier" + 说明 "AI will have a vast impact on the world. Anthropic is a public benefit corporation dedicated to securing its benefits and mitigating its risks."
3. 当前旗舰模型 Banner（Claude Haiku 5.5）
4. "Latest releases" 发布卡片（Introducing Haiku 5.5 / Sonnet 5.5 / Opus 5.5，CTA "Read announcement"）
5. 使命声明 "At Anthropic, we build AI to serve humanity's long-term well-being."
6. 专题卡片（Claude Science、Core views on AI safety、Responsible Scaling Policy、Anthropic Academy、Economic Index、Claude's Constitution）
7. 9 组超级页脚 + Cookie 设置

**Microsoft AI 首页【实测】**
1. 首屏：H1 "Build what's next with Microsoft AI" + 价值说明 + 双 CTA
2. AI 助手入口（AI-powered assistant）
3. 转型资源："Advance your AI journey"（AI Strategy Roadmap、AI Decision Brief、四个精选资源）
4. 人物故事："The people behind AI breakthroughs" / "Hear from leaders behind the work"
5. 产品矩阵："Explore Microsoft AI products for every business need"（7 张卡片，每张一句价值描述）
6. 信任："Build business value with trusted AI"（安全治理、数据保护、负责任 AI）
7. 行业：11 个行业（消费品、教育、能源、金融、政府、医疗、制造、传媒、出行、零售、电信）
8. 新闻、活动、洞察卡片流（20+ 条卡片）
9. FAQ

### 2.2 四类首页编排模板（归纳）

| 模板 | 区块顺序 | 代表 |
|---|---|---|
| **① 研究机构型** | 使命大字 → 最新发布 → 研究/政策专题 → 新闻 → 超级页脚 | Anthropic、DeepMind、OpenAI |
| **② 产品即官网型** | 对话/搜索输入框 →（可选）功能示例 → 下载 App → 极简页脚 | Perplexity、Kimi、DeepSeek、z.ai |
| **③ 云门户运营型** | 轮播 Banner → 活动/新客专享 → 热门产品网格 → 大模型专区 → 解决方案（行业）→ 客户 Logo 墙 → 数字背书 → 新闻 → 注册引导条 → 超级页脚 + 悬浮客服 | 阿里云、腾讯云、百度智能云、华为云、火山引擎 |
| **④ 工业软件解决方案型** | 品牌主张 + 视频/渲染首屏 → 平台/产品族 → 按行业 → 客户成功故事（含量化成果）→ 资源（白皮书、研讨会）→ 活动大会 → 试用/联系 CTA 条 → 超级页脚 | 西门子、达索、Autodesk、PTC、用友、金蝶 |

### 3.2 配图归纳：八种视觉语言
1. **抽象生成艺术**：AI 研究机构的主流，规模化、风格统一，回避具象。
2. **手绘 / 插画**：建立人文感和品牌个性（Anthropic）。
3. **产品输出即配图**：生成式产品用真实输出作主视觉（Runway、海螺）。
4. **写实渲染**：硬件、零件、整机（NVIDIA、中望）。
5. **数字孪生叠加**：实景 + 线框 / 网格 / 数据标签，工业软件最典型的母题（西门子、达索、Bentley）。
6. **科学可视化**：仿真云图、点云、芯片版图（Ansys、Hexagon、Synopsys）。
7. **真实人物与客户作品**：增强可信度（Microsoft、Autodesk）。
8. **架构图 / 数据图**：平台型企业解释"我们是什么"（树根互联、用友）。

> **共同禁区**：通用图库照片（握手、看屏幕的白领）、机器人、发光大脑、代码雨、蓝色神经网络连线图，这些会削弱信任和差异化【公开：行业趋势文章】。

## 4. 设计与交互

### 4.1 首屏形态

| 首屏形态 | 说明 | 代表 |
|---|---|---|
| 大字声明 | 一句使命/主张 + 一段说明，无大图 | Anthropic【实测】、xAI |
| 对话/搜索输入框 | 首屏即产品，输入后直达应用 | OpenAI【公开】、Perplexity、Kimi、z.ai |
| 极简字标 | 只有字标 + 标语 + 入口卡片 | DeepSeek【公开】 |
| 旗舰发布 | 单一模型/产品发布 + 视频 | DeepMind、NVIDIA |
| 双 CTA 价值主张 | 标题 + 价值说明 + 主次两个按钮 | Microsoft AI【实测】、工业软件普遍 |
| 轮播 Banner | 3—6 帧活动、发布轮播 | 国内云厂商、中望、用友 |
| 全屏视频/渲染 | 背景视频 + 叠加标题 | 达索、西门子、Runway |

### 4.2 组件与交互模式清单

| 模式 | 用途 | 代表 | 建议 |
|---|---|---|---|
| Mega Menu | 庞大产品目录 | 阿里云、NVIDIA、西门子 | 分类 + 推荐 + 搜索三栏；移动端改为抽屉 |
| 页内锚点子导航（建议吸顶） | 长页面快速定位 | Microsoft AI【实测】 | 解决方案页、产品页必备 |
| 发布卡片流 | 新品/新闻 | Anthropic【实测】、OpenAI | 统一卡片比例与封面风格 |
| Tab / 分区切换 | 行业 / 产品 / 场景 | Microsoft AI 行业区（11 个行业）【实测】 | Tab ≤ 7 项，超出用下拉 |
| 横向滚动卡片 | 新闻、活动、案例 | 新闻/活动区常用 | 提供左右按钮和指示器 |
| 轮播 Banner | 活动营销 | 国内云厂商 | 不超过 4 帧，可暂停（无障碍） |
| 对话输入框 | AI 产品入口 | OpenAI、Perplexity | 预置示例问题降低门槛 |
| 顶部公告条 | 新版本/活动 | DeepSeek【公开】 | 单行、可关闭 |
| 悬浮咨询 / 客服 | 销售转化 | 国内云厂商、用友、金蝶 | 不遮挡内容，移动端收起 |

| 客户 Logo 墙 / 案例卡 | 信任背书 | 几乎所有 B2B | 案例卡写"挑战—方案—量化成果" |
| 资源中心筛选 | 白皮书、研讨会、文档 | 西门子、PTC、Autodesk | 按类型 / 行业 / 产品筛选 |

| Cookie 同意 | 合规 | Anthropic【实测】、海外站 | 国内站另需 ICP 备案号、公安备案 |
| 深浅色切换 | 开发者友好 | Hugging Face | 可选 |
| 3D / WebGL 查看器 | 产品/孪生展示 | 工业专题页 | 懒加载并提供静态回退图【公开：行业趋势】 |

### 4.3 动效
- **品牌符号动效**：Perplexity 旋转星号、Gemini 粒子、OpenAI 脉动蓝色圆盘、Anthropic Lottie【公开 / 实测】。
- **主流"克制动效"**：滚动渐显、卡片悬停轻微上浮或放大封面、按钮箭头位移、数字计数。
- **重动效集中在专题页**：模型发布页、年度大会页、品牌战役页（Autodesk "Let There Be Anything"、Cohere 动态排版）。
- **注意**：自动播放视频需静音并提供暂停按钮；尊重 `prefers-reduced-motion`。

### 4.4 响应式与性能
- 移动端：Mega Menu 改为全屏抽屉加手风琴；锚点子导航改为横向滚动胶囊。
- 重型视频和 3D 资源需懒加载并提供海报图；首屏 LCP 建议 < 2.5s。
- 工业 B2B 买家大量在线自助调研，网站加载慢或信息难找会被直接淘汰【公开：行业趋势】。

### 5.5 证据型内容（可信度设计）
- **量化成果**：客户案例写"缩短 XX% 研发周期 / 降低 XX% 成本"。
- **规模数字**：服务客户数、连接设备数、日均调用量。
- **第三方背书**：分析师报告（Gartner、IDC）、奖项、认证（ISO、等保、信创）。
- **透明度内容**：Anthropic 把 Responsible Scaling Policy、Transparency、Trust center、Claude's Constitution 放进一级导航【实测】，"安全与透明"本身成为营销内容。
- **公开品牌手册**：Kimi、MiniMax、PTC、Autodesk 公开品牌规范【公开】，同时服务媒体、合作伙伴和开发者。

## 7. 可直接复用的检查清单

- [ ] 主导航 ≤ 7 项；产品线多时使用 Mega Menu，并附带搜索
- [ ] 导航右侧固定 1 个主 CTA + 1 个次 CTA（如"预约演示" + "登录"）
- [ ] 首屏一句话说清"我们是谁 / 为谁 / 带来什么价值"，副文案 ≤ 2 行
- [ ] 首页包含：最新发布 / 产品平台 / 行业方案 / 客户案例（量化）/ 信任与合规 / 资源 / 新闻 / CTA 条
- [ ] 配图风格只选 1—2 种视觉语言，建立统一的封面图规范
- [ ] 不使用通用图库照片、机器人、发光大脑
- [ ] CTA 文案使用"具体动词 + 具体对象"
- [ ] 案例卡片使用"挑战 — 方案 — 量化成果"结构
- [ ] 超级页脚：产品、方案、资源、公司、法律合规、社交媒体、ICP 备案
- [ ] 中英双语 / 区域站规划，支持自动识别与手动切换
- [ ] 动效克制，支持 `prefers-reduced-motion`；视频静音并可暂停
- [ ] 3D / 视频懒加载并提供海报图；首屏 LCP < 2.5s
