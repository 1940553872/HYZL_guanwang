# 四、对 HYZL 官网设计的启示与建议

> 本篇基于 [01](./01-ai-companies-design.md)、[02](./02-industrial-software-design.md)、[03](./03-interaction-and-content.md) 的调研结论。
> **前提假设**：HYZL 定位为"人工智能 + 工业软件 / 智能制造"方向的企业，目标客户以制造业企业决策者、工程师和合作伙伴为主。如果实际定位不同，请调整第 1 节后再看后续建议。

---

## 1. 核心结论（一句话版）

> **用 AI 头部的"克制与温度"做品牌气质，用工业软件头部的"证据与场景"做内容骨架，用一个差异化强调色和统一的"数字孪生 × AI"视觉母题建立辨识度。**

| 借鉴来源 | 借鉴什么 | 不借鉴什么 |
|---|---|---|
| AI 头部（Anthropic、OpenAI、DeepSeek） | 大留白、一句话首屏、定制感字体、发布卡片流、透明与信任内容 | 过度抽象、只讲使命不讲场景 |
| 工业软件头部（西门子、达索、Autodesk） | 数字孪生视觉、行业 × 产品索引、量化客户案例、资源中心 | 过度庞杂的 Mega Menu、过长的产品 A-Z |
| 国内云厂商 | 清晰的转化入口、在线咨询、中文排版习惯 | 轮播 Banner 堆砌、促销化视觉 |

---

## 2. 三个视觉方向提案

### 方向 A：理性工业极简（推荐作为主方向）
- **气质**：精密、可靠、克制，"工程师的审美"
- **参考**：OpenAI 的极简、NVIDIA 的单色点缀加直角、DeepSeek 的安静
- **色彩（建议值，需结合 Logo 确定）**

| Token | 建议色值 | 用途 |
|---|---|---|
| `--color-ink` | #0E1116 | 主文字、深色区背景 |
| `--color-paper` | #F7F7F5 | 页面背景（略暖的白，避免纯白刺眼） |
| `--color-line` | #E4E4E0 | 分割线、卡片描边 |
| `--color-muted` | #6B6F76 | 次要文字 |
| `--color-accent` | 二选一：**熔岩橙 #F25C1F** / **钛金黄 #F2B705** | CTA、链接、数据高亮（只做"点"，不铺"面"） |
| `--color-data` | #2E7DFF | 数据可视化、图表（与强调色区分功能） |

- **字体**：中文 思源黑体 / HarmonyOS Sans / 阿里巴巴普惠体（均可免费商用，以各自授权协议为准）；英文与数字 Inter 或 Geist；代码和参数 Geist Mono / IBM Plex Mono
- **组件**：小圆角（2—4px）、1px 描边、几乎不用阴影
- **为何推荐**：国内工业软件普遍是蓝色科技风（见 02 篇 §5.1），一个非蓝强调色能快速区隔；极简框架也最能承载大量工业内容

### 方向 B：温暖可信 AI
- **气质**：人文、亲和、负责任
- **参考**：Anthropic 的象牙白 + 陶土橙 + 衬线标题、MiniMax 的自然生机、Microsoft Copilot 的暖光
- **适用**：面向大众或强调"AI 安全、可信、以人为本"的品牌叙事
- **风险**：在工业客户眼中可能显得"不够硬"，建议只用于品牌故事页和关于我们

### 方向 C：深色数字孪生
- **气质**：未来感、沉浸、技术冲击力
- **参考**：西门子 Xcelerator 深色 + 光效、达索电影级渲染、NVIDIA 暗场
- **适用**：首屏、产品发布专题页、展会大屏
- **风险**：通篇深色会降低长文可读性，建议"深色首屏 + 浅色正文"的双模式（工业软件头部的通行做法）

> **推荐组合**：**A 为全站基调 + C 用于首屏和发布专题 + B 的手绘/人文元素用于"关于我们"和品牌故事**。

## 3. 推荐信息架构（Sitemap）

```
首页
├─ 产品与平台          （平台总览 / 产品 A / 产品 B / 工业 AI 智能体 / 产品对比）
├─ 解决方案            （按行业：离散制造 / 流程工业 / 能源 / 建筑…  按场景：研发设计 / 生产运营 / 设备运维 / 质量）
├─ 客户案例            （按行业筛选；每个案例：挑战—方案—量化成果）
├─ 资源中心            （白皮书 / 技术博客 / 研讨会 / 文档与 API / 下载中心）
├─ 研究与技术          （技术路线 / 论文与专利 / 开源 / 可信 AI 与安全）   ← 借鉴 AI 头部
├─ 关于 HYZL           （公司简介 / 发展历程 / 团队 / 新闻 / 加入我们 / 联系我们）
└─ 导航右侧            [ 预约演示 ]（主 CTA）  [ 登录 / 控制台 ]  [ 中 / EN ]  [ 搜索 ]
```

- 一级导航控制在 **6 项**；产品线少于 10 个时用"分组下拉"即可，不必上 Mega Menu
- 解决方案、产品详情等长页面使用**吸顶的页内锚点子导航**（参照 Microsoft AI 页面的 9 个锚点）
- 如有在线 Demo 或开发者平台，按 AI 头部惯例**独立成产品站或子域**，主站专注品牌和转化

## 4. 首页区块线框（自上而下）

| # | 区块 | 内容要点 | 参考 |
|---|---|---|---|
| 0 | 公告条（可关闭） | 最新产品 / 版本 / 大会，单行 | DeepSeek、阿里云 |

## 5. 配图规范建议
1. **只选两种主视觉语言**：
   - ①"**数字孪生叠加**"：真实工厂/设备照片 + 线框/网格/数据标签叠加（行业最强母题，见 02 篇 §5.3）；
   - ②"**统一风格的抽象/插画系统**"：用于新闻、博客、研究文章封面（参照 DeepMind 用统一工具批量产出风格一致的配图）。
2. **真实优先**：客户现场、团队、产品界面实拍或真实截图；杜绝通用图库照片。
3. **AI 生成图可用，但要风格化、可识别**：建立固定的提示词、色调和构图模板，保证一致性。
4. **禁用意象**：机器人、发光大脑、代码雨、蓝色神经网络连线图、握手商务照。
5. **数据可视化**：统一图表配色（`--color-data` 加中性灰阶），数字注明口径和时间。

## 6. 文案框架

### 6.1 品牌主张公式（三选一）
| 公式 | 结构 | 参考 |
|---|---|---|
| 行动邀请式 | 动词 + 对象 + 价值 | "Accelerate your digital transformation"、"Build what's next" |
| 世界观式 | 抽象愿景，一句话 | "Virtual Worlds for Real Life"、"探索未至之境" |
| 定位声明式 | 我们是 + 品类 | "We are the 3DEXPERIENCE Company"、"工业操作系统" |

> 建议首屏用**行动邀请式**（B2B 转化），"关于我们"页用**世界观式**（品牌高度）。

### 6.2 文案原则
- **先价值、后能力**：先说客户得到什么（周期缩短、成本降低、良率提升），再说技术。
- **具体 CTA**：用"预约 30 分钟场景诊断""下载《XX 白皮书》"代替"了解更多"。
- **发布体统一**："全新发布｜XXX"或"Introducing XXX"，日期 + 一句价值 + 阅读入口。
- **少用空话**："赋能、千行百业、全面、领先"等词每页限 1 次。
- **中英双语**：英文版单独撰写，不直译中文。

## 7. 交互规范要点
- 导航：吸顶、滚动后收窄；移动端改为抽屉加手风琴
- 首屏视频：静音自动播放 + 暂停按钮 + 海报图回退
- 动效：滚动渐显、卡片悬停上浮 2—4px，支持 `prefers-reduced-motion`
- 咨询：右下角悬浮"预约演示/在线咨询"，移动端收为图标
- 表单：预约演示表单 ≤ 5 个字段（姓名、公司、职位、手机/邮箱、需求）
- 性能：首屏 LCP < 2.5s；3D/WebGL 懒加载
- 合规：Cookie/隐私提示、ICP 备案、隐私政策、用户协议
- 多语言：中 / EN，支持自动识别与手动切换（参照金蝶 2025 改版）

## 8. 下一步建议
1. **确认定位**：HYZL 的业务领域、核心产品、目标客户（决定方向 A/B/C 的权重）。
2. **截图核验**：本调研受环境网络限制，多数官网未能实时打开。建议用浏览器对 [README](./README.md#核验清单) 中的核验清单逐一截图（桌面 1440px + 移动 390px），补充到 `research/screenshots/`。
3. **情绪板（Moodboard）**：按方向 A/B/C 各整理 8—12 张参考截图，与团队评审。
4. **品牌基础**：确定 Logo、强调色、字体后，输出 Design Tokens（色彩、字号、间距、圆角）。
5. **线框到视觉**：按第 4 节区块先出低保真线框，再出 2 套视觉稿对比。
