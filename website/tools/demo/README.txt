华云智联官网 V2.0 —— 静态演示包

使用方法（只需要电脑上装有 Node.js 18 或更高版本）：
  Windows：双击 open-demo.bat，浏览器会自动打开 http://localhost:3000
  macOS / Linux：在终端运行 ./open-demo.sh
  关闭命令行窗口即停止演示。

说明：
  · 本演示包由完整网站预渲染生成，页面内容、图片与交互（导航、筛选、灯箱、动画等）与正式站点一致。
  · 演示版没有后端服务：站内搜索不可用；“预约现场演示”等表单只演示校验与提交成功状态，不会保存或发送数据。
  · 完整版（含内容服务、搜索、留资）请按仓库 website/docs/本地部署说明.md 部署。
