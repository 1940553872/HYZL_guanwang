# ADR-0002：统一内容表（content_item + body_json）

- 状态：已采纳（2026-10-08）
- 关联：K-05 §3 数据模型

## 背景

现网内容有 14 类：产品、方案、案例、新闻、标准、专利、软著、项目、奖项、证书、合作单位、实验室、职位、页面配置。

- 各类公共字段相同：标题、slug、分类、排序、发布 / 到期、授权、归档。
- 各类特有字段差异很大：标准有编号、状态、角色、证明材料；项目有级别、来源、经费。
- 产品正文是"能力条目 / 参数表 / 图片"组成的结构化块。

K-05 的目标模型是每类一张表加版本表，配合后台编辑使用。本期没有后台编辑（ADR-0003），内容全部来自素材库生成的种子。

## 决策

1. 使用一张 `content_item` 表，以 `(content_type, slug, locale)` 唯一。
   - 公共字段建为列，以支持筛选与排序。
   - 特有字段存入 `body_json`（TEXT），接口原样输出为 `data`。
2. 内容以种子 JSON 为唯一来源。启动时比较种子哈希，变化时在事务中整体替换。
3. 正文使用结构化块 `{t: p|h|cap|img}`，不存 HTML。前端用 `ContentBlocks` 渲染，不存在 XSS 注入面。

## 影响

- 新增内容类型只需加种子和前端页面，无需迁移数据库。
- 将来上线后台编辑时，再按 K-05 拆分为分类型表、增加版本表，并把种子导入改为一次性迁移。届时 `body_json` 可在 PostgreSQL 中改为 `jsonb`。
- 搜索在内存中对 `body_json` 的文本字段做包含匹配，并排除结构字段（`t`、`src`、`kind` 等），以免误命中。
