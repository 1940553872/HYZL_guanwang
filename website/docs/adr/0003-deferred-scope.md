# ADR-0003：本期范围与延后事项

- 状态：已采纳（2026-10-08）

本期目标：基于现有素材做出可本地运行、可评审的完整官网（中文站 P0 页面）。以下事项依赖尚未就绪的外部条件，本期不做，并在代码中留好接口或降级方案。

| 事项 | 设计出处 | 延后原因 | 本期处理 |
|---|---|---|---|
| 内容管理后台 hyzl-admin、OIDC SSO、RBAC | K-05 §2.3、§5 | SSO 提供方【待确认】；内容以素材库为准 | 种子 JSON + `build_content.py`；线索管理用 Bearer 令牌接口，未配置令牌时关闭（403） |
| 资料下载 P-61（白皮书 / 手册） | K-02 §2.1、design_document 待确认 #9 | 资料未制作 | 服务支持页显示"整理中"，引导留资索取 |
| 英文站 `/en/` | K-02 §2.1（P1） | P1 范围 | 未实现；内容模型已有 `locale` 字段 |
| 验证码 | K-05 §2.2 | 云厂商未确定 | 蜜罐字段 + 每 IP 限流 + 24 小时去重 |
| Redis 缓存与分布式限流 | K-05 §4 | 本地单实例不需要 | 进程内滑动窗口限流；多实例前必须替换 |
| 线索通知（企业微信 / 邮件） | K-05 §1.1 | Webhook 未提供 | 写入日志（不含个人信息） |
| 视频（企业风采） | 待确认 #10 | 优酷无播放权限 | 不展示 |
| 客户 Logo 墙 | 待确认 #4 | 授权未确认 | 首页以文字列出客户名称，标注"部分"；合作单位页说明"不代表客户关系" |
| 容器化、CDN、监控 | K-07 | 云服务商【待确认】 | 本地一键脚本；健康检查接口已具备，可直接接入探针 |
