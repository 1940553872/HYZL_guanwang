# 华云智联官网 V2.0：本地部署说明

本文说明如何在一台电脑上运行新版官网，用于演示、评审和联调。生产部署（CDN、WAF、PostgreSQL 高可用、监控告警）按 [design_document/K-07](../../design_document/K-07-sre.md) 执行，不在本文范围内。

## 0. 只想看演示效果：静态演示包（最快）

不需要 Java，也不需要构建，只要电脑上装有 Node.js 18 或以上版本：

1. 取得 `hyzl-website-demo.zip`：由开发者提供，或在本仓库运行 `./tools/build-demo.sh` 生成到 `dist/`。
2. 解压后：
   - Windows：双击 `open-demo.bat`
   - macOS / Linux：运行 `./open-demo.sh`
3. 浏览器会自动打开 http://localhost:3000。

演示包由完整网站预渲染生成（82 个页面），内容、图片与交互和正式站点一致。没有后端，所以：

- 站内搜索不可用；
- 表单只演示校验和"提交成功"状态，不保存数据。

## 1. 一分钟上手

```bash
cd website
./start.sh        # 首次运行会自动构建，约 3–6 分钟；之后再启动约 10 秒
# 浏览器打开 http://localhost:3000
./stop.sh         # 停止
```

**Windows**：在 `website` 文件夹中双击 `start.bat` 启动，双击 `stop.bat` 停止。在 PowerShell 或 CMD 中则运行：

```powershell
cd D:\你的路径\website
.\start.bat      # 启动（窗口最后会提示“按任意键继续”）
.\stop.bat       # 停止
```

> ⚠️ Windows 上**不要运行 `./start.sh`**。Windows 不能直接执行 `.sh` 文件，会用关联程序（如 VS Code）打开它，看起来像“报错”，其实站点并没有启动。`.sh` 脚本只用于 Linux / macOS，或 Windows 上的 Git Bash / WSL。

## 2. 运行环境

| 软件 | 版本要求 | 检查命令 | 说明 |
|---|---|---|---|
| JDK | **21** 或更高 | `java -version` | 推荐 Eclipse Temurin 21 LTS 或毕昇 JDK 21。只装 JRE 不够，构建需要 JDK |
| Node.js | **22.22.3+ 或 24.15+**（Nuxt 4.6 官方支持范围；低于此版本脚本会提示） | `node -v` | 自带 npm |
| curl | 任意 | `curl --version` | Linux / macOS 脚本用于健康检查；Windows 不需要 |
| 磁盘 | 约 1.5 GB | — | Maven 依赖约 300 MB，npm 依赖约 500 MB |
| 内存 | 2 GB 空闲 | — | 内容服务限制最大堆 512 MB |
| 网络 | 首次构建需要联网 | — | 下载 Maven 与 npm 依赖；构建完成后可离线运行 |

不需要安装 Maven、数据库或 Docker：

- `apps/api/mvnw` 会自动下载 Maven 3.9.11。
- 本地运行使用内置 H2 文件数据库，以 PostgreSQL 兼容模式运行。

### 2.1 国内网络加速（可选）

npm 镜像：

```bash
npm config set registry https://registry.npmmirror.com
```

Maven 镜像：在 `~/.m2/settings.xml` 中加入阿里云镜像。

```xml
<settings>
  <mirrors>
    <mirror>
      <id>aliyun</id>
      <mirrorOf>central</mirrorOf>
      <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
  </mirrors>
</settings>
```

Maven 本体下载失败时，可设置 `MVNW_REPOURL=https://maven.aliyun.com/repository/public` 后重试。

## 3. 组成与端口

```text
浏览器 ──► 网站 hyzl-web（Nuxt 4 SSR，端口 3000）
              │  /api/v1/* 由网站服务端代理转发
              ▼
           内容服务 hyzl-api（Spring Boot 4，端口 8080，仅监听 127.0.0.1）
              │
              ▼
           H2 文件数据库（website/data/）← 启动时自动导入 seed 内容
```

| 服务 | 地址 | 用途 |
|---|---|---|
| 网站 | http://localhost:3000 | 官网全部页面 |
| 网站健康检查 | http://localhost:3000/api/health | 返回网站与内容服务状态 |
| 内容服务健康检查 | http://127.0.0.1:8080/actuator/health | `{"status":"UP"}` |
| 接口文档（Swagger UI） | http://127.0.0.1:8080/api/v1/docs | 公开接口说明与在线调试 |
| OpenAPI JSON | http://127.0.0.1:8080/api/v1/openapi | 供 Apifox / Postman 导入 |

## 4. 脚本用法

Linux / macOS 使用 `hyzl.sh`。`start.sh` 和 `stop.sh` 是它的简写。

| 命令 | 作用 |
|---|---|
| `./hyzl.sh start` | 检查环境，缺少产物时先构建，然后后台启动两个服务，等待健康检查通过 |
| `./hyzl.sh start --rebuild` | 强制重新构建后启动。拉取新代码或修改内容后使用 |
| `./hyzl.sh stop` | 停止两个服务。先发送正常退出信号，10 秒后仍未退出则强制结束 |
| `./hyzl.sh restart [--rebuild]` | 先停止，再启动 |
| `./hyzl.sh status` | 查看进程与健康检查结果 |
| `./hyzl.sh logs api` / `logs web` | 跟踪日志（Ctrl+C 退出） |

Windows 使用 `hyzl.ps1`，`start.bat` / `stop.bat` 会调用它。也可以在 PowerShell 中直接运行：

```powershell
powershell -ExecutionPolicy Bypass -File hyzl.ps1 start -Rebuild
powershell -ExecutionPolicy Bypass -File hyzl.ps1 status
```

运行时文件：

| 路径 | 内容 |
|---|---|
| `.run/api.pid`、`.run/web.pid` | 进程号，`stop` 据此停止服务 |
| `.run/logs/api.log`、`web.log`、`web-build.log` | 运行与构建日志 |
| `data/` | 本地数据库（内容与留资线索）。删除后，下次启动会重新导入内容，线索会被清空 |

## 5. 环境变量

在命令前设置即可，例如 `WEB_PORT=3001 ./start.sh`。Windows CMD 用 `set WEB_PORT=3001` 后再运行 `start.bat`；PowerShell 用 `$env:WEB_PORT=3001` 后再运行 `.\start.bat`。

| 变量 | 默认值 | 说明 |
|---|---|---|
| `WEB_PORT` | `3000` | 网站端口 |
| `API_PORT` | `8080` | 内容服务端口 |
| `HYZL_HOST` | `127.0.0.1` | 网站监听地址。局域网内演示可设为 `0.0.0.0`，同事通过 `http://<本机IP>:3000` 访问 |
| `NUXT_PUBLIC_SITE_URL` | `http://localhost:<WEB_PORT>` | 站点绝对地址，用于 canonical、sitemap、分享图 |
| `HYZL_DATA_DIR` | `website/data` | 数据库目录 |
| `HYZL_ADMIN_TOKEN` | 空（关闭） | 设置后启用线索管理接口 `/admin/v1/leads`，见第 7 节 |
| `HYZL_SM4_KEY` | 内置演示密钥 | 手机号、邮箱字段加密密钥（Base64 编码的 16 字节）。**内置值仅供本地演示，任何对外环境都必须替换** |
| `HYZL_HMAC_KEY` | 内置演示密钥 | 线索去重哈希密钥。同上，必须替换 |
| `HYZL_SEED_MODE` | `auto` | `auto`：seed 文件变化时重新导入；`always`：每次启动都导入；`never`：不导入 |
| `DB_URL` / `DB_USER` / `DB_PASSWORD` | H2 | 改用 PostgreSQL 时设置，见第 8 节 |

## 6. 修改内容

网站内容来自 `apps/api/src/main/resources/seed/*.json`，由 `tools/build_content.py` 根据仓库根目录的 `素材库/` 生成。

```bash
# 1) 修改素材库文字或图片后，重新生成 seed 与图片（需要 Python 3.10+ 与 Pillow）
pip install pillow
python3 tools/build_content.py              # 同时重新生成 WebP 图片
python3 tools/build_content.py --skip-media # 只更新文字

# 2) 重新构建并启动（内容服务会自动检测 seed 变化并重新导入）
./hyzl.sh restart --rebuild
```

小幅修改可以直接编辑 seed JSON，再执行 `./hyzl.sh restart --rebuild`。seed 已打包进 jar，所以必须重新构建。

内容规则（由内容服务执行）：

- 案例 `authorized=false` 时不对外返回。
- 证书过期后自动下线，距到期 ≤ 60 天时显示"即将到期"。
- 首页"最新动态"区块只在近 12 个月新闻 ≥ 3 条时显示。

## 7. 查看留资线索

"预约现场演示"与"联系我们"表单提交的线索保存在本地数据库中，手机号和邮箱加密存储。启用管理接口：

```bash
HYZL_ADMIN_TOKEN=换成你自己的长随机串 ./hyzl.sh restart

# 列表（默认脱敏：138****8000）
curl -H "Authorization: Bearer <令牌>" http://127.0.0.1:8080/admin/v1/leads
# 查看明文（会写入审计日志）
curl -H "Authorization: Bearer <令牌>" "http://127.0.0.1:8080/admin/v1/leads?reveal=true"
# 更新状态：new → assigned → contacted → qualified；qualified 之前可改为 invalid，invalid 可重新 assigned
curl -X PATCH -H "Authorization: Bearer <令牌>" -H "Content-Type: application/json" \
     -d '{"status":"assigned","notes":"已分配销售"}' http://127.0.0.1:8080/admin/v1/leads/<线索ID>
```

可视化管理后台（hyzl-admin）不在本次范围内，见 [ADR-0003](./adr/0003-deferred-scope.md)。

## 8. 改用 PostgreSQL（可选）

本地默认使用 H2，无需安装数据库。如需与生产环境一致，可改用 PostgreSQL 16 及以上：

```bash
createdb hyzl && createuser hyzl -P      # 密码设为 hyzl，或按需修改
DB_URL=jdbc:postgresql://localhost:5432/hyzl DB_USER=hyzl DB_PASSWORD=hyzl ./hyzl.sh restart
```

表结构由 Flyway 自动创建（`apps/api/src/main/resources/db/migration`），内容自动导入。

## 9. 开发模式（前端热更新）

```bash
# 终端 1：内容服务
cd apps/api && ./mvnw spring-boot:run
# 终端 2：网站（修改 .vue 文件后页面自动刷新）
cd apps/web && npm install && npm run dev
```

## 10. 测试

```bash
# 后端：单元测试 + 接口集成测试（H2 内存库）
cd apps/api && ./mvnw test
# 前端：单元测试
cd apps/web && npm test
# 端到端：先 ./start.sh 启动站点，再运行（桌面 1440 与移动 Pixel 7 两组）
cd apps/web && npx playwright install chromium   # 首次需要
npx playwright test
```

端到端用例会真实提交两条测试线索。内容服务按"每 IP 10 分钟 5 次"限流，短时间内连续运行会返回 429。遇到这种情况，等 10 分钟或执行 `./hyzl.sh restart`。

## 11. 常见问题

| 现象 | 原因与处理 |
|---|---|
| `端口 3000 已被占用` | 其他程序占用了端口。换端口：`WEB_PORT=3001 ./start.sh`；或先执行 `./stop.sh` |
| `Java 版本为 17，需要 21 或更高版本` | 安装 JDK 21，并让 `java` 指向它（检查 `JAVA_HOME` 与 `PATH`） |
| 首次构建卡在下载依赖 | 网络问题，参照 2.1 配置国内镜像后执行 `./hyzl.sh start --rebuild` |
| `内容服务启动超时` | 查看 `.run/logs/api.log`。常见原因：端口冲突、`data/` 目录无写权限、`HYZL_SM4_KEY` 不是 16 字节 |
| 浏览器显示 Nuxt 自带的 "500 undefined / This page is temporarily unavailable"，`.run/logs/web.err.log` 中有 `Either manifest or precomputed data must be provided` | 前端构建产物缺少客户端资源清单（旧版本在 Windows 上构建会出现）。拉取最新代码后运行 `.\hyzl.ps1 start -Rebuild`（或 `./hyzl.sh start --rebuild`）。新版本构建后会自检，启动脚本发现产物不完整也会自动重建 |
| 页面显示"服务暂时不可用"（500） | 内容服务没在运行。执行 `./hyzl.sh status`，再查看 `api.log` |
| 修改了 seed 但页面没变 | seed 打包在 jar 中，需要执行 `./hyzl.sh restart --rebuild` |
| 想清空所有数据重来 | `./stop.sh && rm -rf data && ./start.sh` |
| Windows 上运行 `./start.sh` 后打开了 VS Code 或记事本，并输出一堆 `ssl_client_socket ... handshake failed` 日志 | `.sh` 文件在 Windows 上会被关联程序打开，那些日志是编辑器自己的，与本站无关。改为运行 `.\start.bat` |
| Windows 双击 `start.bat` 窗口一闪而过 | 在 PowerShell 中手动运行 `powershell -ExecutionPolicy Bypass -File hyzl.ps1 start` 查看报错 |
| Windows 上本机装有 Clash 等代理软件 | 脚本的健康检查直连 127.0.0.1，不经过系统代理；首次构建下载依赖时如果代理导致失败，参照 2.1 配置国内镜像 |
| 公司电脑禁止运行 PowerShell 脚本 | 使用 Git Bash 或 WSL 运行 `./start.sh` |

## 12. 安全提示

- 内置的 `HYZL_SM4_KEY`、`HYZL_HMAC_KEY` 是公开的演示值，只能用于本机演示。
- 内容服务默认只监听 `127.0.0.1`，网站默认只监听 `127.0.0.1`。设为 `0.0.0.0` 对局域网开放时，不要在公网机器上这样做。
- `data/` 中保存了测试线索。演示结束后可以删除。
