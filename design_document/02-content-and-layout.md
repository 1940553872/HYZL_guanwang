## 1. 定位与总策略

**一句话**：让访客在 10 秒内知道"华云智联用工业智能体集群解决现场问题，并且有标准和客户背书"，在 3 分钟内找到对口方案并留资。

两份调研给出的方向（AI 官网"产品即入口"、工业软件官网"方案即入口"）在华云智联身上需要合并：

| 层次 | 借鉴 | 在华云智联的落地 |
|---|---|---|
| 首屏 | AI 企业：一句主张 + 一个入口，不用轮播 | 使命"让智能释放产业效能" + 副标 + 三个大数字 + "预约现场演示"；不做多帧轮播 |
| 索引 | 工业软件：行业 × 产品 × 痛点三维 | 一级导航给产品与行业，首页用"痛点设问卡"直达 SpatiGo™ 四个子产品 |
| 信任 | 工业软件：Logo 墙 + 大数字 + 第三方背书 | 客户 + 标委会委员身份 + 标准 / 专利 / 软著数字 + 奖项 |
| 证据 | 电影事件派（NVIDIA、华为）+ 西门子"实景叠加数字孪生" | 深色全宽"现场证据"段：具身智能场景、油田特种作业、矿区驾驶舱 |
| 文案 | Siemens"设问 + 结果"、Anthropic 克制 | "高危作业还靠人盯？"→"安全之弈：多模态识别违章，同步报警，人在环上确认" |

**不做**：对话框首屏（工业客户不是来聊天的）；首屏多帧轮播；整屏滚动；文字烧录图片。

## 2. 内容架构（产品体系梳理）

现网产品信息分散在产品中心 16 个面板和关于页产品矩阵里，且名称不一致（见 01 §5 E07、E08）。新站统一按"**平台 → 旗舰产品 → 模型 → 智能体 → 引擎 → 软件 → 安全集成**"组织：

```
盘古华云智能工厂平台（7+10+2+N，iMoM 3.2）          ← 平台总览 P-20
├─ 空间群弈™ SpatiGo™ 工业监管—执行智能体集群（旗舰） ← P-21
│   ├─ 质量之弈：多模态质量采集、SPC 分析、CPK/PPK 能力评估
│   ├─ 运维之弈：工业设备预测性维护 FMEA 智能体
│   ├─ 安全之弈：多模态安全监测与合规执行智能体
│   └─ 具身之弈：旋翼 UAV、轮式 / 四足 / 人形 UGV 混合监管—执行
├─ 工业增强大模型 iMLLM 1.0                           ← P-22
│   （工业多模态应用大模型 + 工业增强 LLM 交互 + 多模态信息融合智能体群控系统）
├─ 工业智能体应用（7 个）                             ← P-23
│   生产智能作业智能体 · AI 质量识别 · 设备预测性维护 · 智能仓储调度 ·
│   应急安全预测预警 · 虚拟数字员工 · 生产智能作业系统
├─ 智能引擎群（7 组：iDCE / iVEE / iGIS / iCTE / iGCE / iKGE / iMDT）  ← P-24
├─ 工业软件（标准软件 + 先进软件，名称以 03 §2 唯一清单为准）        ← P-25
└─ 安全与集成（工业协议、数据安全、数据接口、安全与可靠性）          ← P-26
```

"2"（物理—化学 MPC 硬约束、成本—效率软约束）和"N"（智能体）在 P-20 架构图里解释，不单独成页。

## 6. 整体布局风格

### 6.1 风格定义：**深海军蓝工业极简**
- **基调**：大留白 + 少元素的"理性工业极简"为全站基础；Hero、现场证据、收尾 CTA、页脚使用深海军蓝。
- **从现网演进**：保留 Logo 的蓝 + 橙品牌资产，把"饱和蓝紫渐变 + 光效"收敛为"深海军蓝纯色 + 真实现场图"，把从未使用的华云橙启用为行动色。
- **关键词**：精密、可信、现场感、克制。

### 6.2 色彩（完整 Token 见 [K-01 §2.2](./K-01-ui-visual-design.md)）

| 角色 | 色值 | 用途 |
|---|---|---|
| 华云蓝（Logo） | #05348E | 品牌主色：标题强调、链接、次按钮、图标 |
| 深海军蓝 | #0A1A3F | 深色段背景（Hero、现场证据、CTA、页脚） |
| 华云橙（Logo） | #ED6E37 | 深底上的大数字、高亮、焦点环、装饰线 |
| 行动橙 | #C2471A | 浅底主按钮（白字对比度 4.99）与橙色文字 |
| 纸白 | #F6F7F9 | 页面背景 |
| 墨色 | #0E1726 | 正文 |

> 不再使用蓝紫渐变；红色只用于错误和危险状态；数据图表使用独立的数据色序列。

### 6.3 版式
- 12 列栅格，容器最大宽 1280px；区块间距 PC 128px、移动 64px。
- 字体：中文 HarmonyOS Sans SC（或思源黑体），西文与数字 Inter，参数与代码 JetBrains Mono；全部自托管并子集化；正文不加粗。
- 组件：小圆角 4px、1px 描边、几乎无阴影。
- 内页：放弃"左侧菜单 + 右侧白卡"的后台式布局，改为"页内锚点子导航（吸顶）+ 通栏内容区块"。

### 6.4 配图体系

| 类型 | 用途 | 规范 | 现有素材 |
|---|---|---|---|
| ① 现场实拍 | Hero、现场证据、案例 | 统一调色：压暗、降饱和、保留橙色高光；必须过涉密审查 | 缺口（需拍摄） |
| ② 系统界面 / 驾驶舱 | 产品页 | 真实截图脱敏后放入统一的设备外框 | `product/v2/sw_*`、`adv_*`、`engines.jpg` |
| ③ 架构图 / 流程图 | 平台、产品、方案 | SVG 重绘；线宽 1.5px；只用华云蓝、灰阶和华云橙 | `mmdlm.jpg`、`llm.jpg`、`swarm.jpg`、`agent_pdm_flow.jpg` 作为重绘蓝本 |
| ④ 证书与文件 | 资质、标准 | 统一缩略图比例 3:4，点击灯箱查看，加"仅用于展示"水印 | `about/honor/*`（108 张） |
| ⑤ 统一封面 | 新闻、资料 | 参考 OpenAI Art Card：以点云 / 等高线 / 网格生成，按栏目换明度 | 新做模板 |

**停用**：图库人像（托举双手、办公人像）、蓝紫渐变背景、文字烧录图。

### 6.5 动效
滚动渐显（400ms、位移 16px）；卡片悬停上浮 2px；大数字首次进入视口计数一次；架构图点击展开；尊重"减少动态效果"系统设置。

### 7.2 结构规则
- 首屏 H1 ≤ 12 字，副标 ≤ 2 行；每个区块"**设问 / 价值 → 怎么做到 → 证据 → 行动**"。
- 专业缩写首次出现给一句白话（如 FMEA：故障模式及影响分析）。
- CTA 用具体动词 + 对象：预约现场演示 / 查看延长石油场景 / 下载 SpatiGo™ 产品手册。
- i 系列产品统一写法："iMES 生产执行系统"（编码 + 中文名），英文名首字母大写。

### 7.3 合规红线
- 《广告法》：不用"唯一、第一、领先、首位"，除非附出处与口径（01 §5 E23）。
- 标准表述区分"主编 / 参编 / 委员"和"已发布 / 立项 / 编制中"（E21）。
- 客户名称、Logo、评价需书面授权；"合作单位"不得写成"客户"。
- 所有量化指标附脚注口径；证书显示有效期。
