## 2. 现网视觉风格

| 维度 | 现状 | 评价 |
|---|---|---|
| 主色 | 全站背景为高饱和蓝紫渐变（约 #2A2BD0 一带），叠加光束、网格、粒子纹理 | 属于调研中"蓝紫科技渐变"的同质化风格；与 Logo 的深蓝 + 橙不一致 |
| 品牌标识 | Logo：深蓝弧形 + 橙色"H"+ 深蓝"华云智联"字标；实测主色 **#05348E（华云蓝）**、**#ED6E37（华云橙）** | 品牌色本身辨识度好，但页面完全没用上橙色 |
| 字体 | 系统黑体（微软雅黑 / 思源黑体），大量粗体蓝字 | 正文也用粗体，层级不清 |
| 版式 | 内页统一为"左侧菜单 + 右侧白卡片"的后台式布局 | 信息密度高、无视觉锚点，像技术文档而非官网 |
| 配图 | 图库人像（托举双手、办公人像）、图库机械臂、高校风景、产品架构图（JPG 位图）、证书扫描件 | 真实工业现场照片几乎为零；架构图风格不统一 |
| 文字图片化 | 首页 6 个技术方向、使命句、4 类服务均为**烧录文字的图片** | 不利于 SEO、无障碍和多语言 |
| 动效 | 首页整屏滚动 + 图标位移淡入 | 整屏滚动在移动端和触控板上体验差，且阻碍长内容 |

## 4. 问题诊断

| # | 问题 | 影响 | 对应改版措施 |
|---|---|---|---|
| D1 | 首页无价值主张和行动入口：首屏是 6 个技术名词，旗舰产品 SpatiGo™ 不在首页 | 访客 3 秒内无法判断"你们做什么、为谁" | Hero 改为"使命 + 价值副标 + 三个大数字 + 双 CTA"（02 §4） |
| D2 | 首页"四类服务"（顾问咨询、软件开发、产品设计、系统集成）与关于页"工业 AI 智能体"定位脱节 | 定位模糊，像系统集成商 | 首页以 SpatiGo™ 与平台为主，四类服务下沉到服务支持页 |
| D3 | 产品中心 16 个面板、关于页 9 个子项均在同一 URL 内切换 | 无法分享具体产品链接，搜索引擎只能收录 2 个 URL | 每个产品、每个子栏目独立 URL（K-02 §2） |
| D4 | 全站无任何表单、无"联系销售 / 预约演示"入口，仅有电话 | B 端访客无法留资，转化为零 | 预约现场演示表单 + 悬浮咨询（K-02 §3） |
| D5 | 新闻停更：20 篇全部为 2018—2020 年 | 访客会判断"公司是否还在经营"，与"2026 年发布 SpatiGo™"相矛盾 | 历史新闻归档；上线前补 6 篇以上 2025—2026 年动态；首页新闻模块仅在近 12 个月有 ≥ 3 篇时显示 |
| D6 | 案例只有 3 个（湖大艾盛、长城金融、中电软件园），属于早期工业云项目，与当前工业 AI 定位不匹配；长庆油田、延长石油等新案例只散落在产品文字里 | 缺少可信的现场证据 | 新建 3—5 个工业 AI 案例（挑战—方案—量化成果），旧案例标"历史案例" |
| D7 | 产品页像招标技术规范：参数、标准号、协议速率全部平铺 | 决策者读不下去，招采人员找不到要点 | "价值 → 能力 → 证据 → 规格（折叠 + 规格书下载）"四层结构 |
| D8 | 文字烧录在图片中（首页 6 方向、使命、4 类服务） | SEO、无障碍、英文版全部受损 | 全部改为 HTML 文本 |
| D9 | 饱和蓝紫渐变 + 图库人像 | 同质化、廉价感，与 Logo 色不一致 | 深海军蓝 + 华云橙 + 真实工业现场（K-01） |
| D10 | 整屏滚动（fullPage），第 6 个圆点为空白屏 | 移动端体验差，有明显 bug | 改为常规滚动 |
| D11 | 企业风采视频为优酷嵌入，提示"该视频暂无播放权限" | 页面出现失效内容 | 视频自托管（对象存储 + CDN） |
| D12 | "合作单位"43 个标识与"客户"混用的风险 | 可能被误读为客户背书，引发合规问题 | 客户、合作伙伴分开展示，并逐一确认授权 |
| D13 | 资质证书有效期临近：高新技术企业证书 2023-12-12 发证、有效期三年（约 2026-12 到期）；ISO 9001 至 2027-01-15 | 上线时可能展示过期证书 | 证书数据带"有效期"字段，到期前 60 天提醒（K-05） |
| D14 | 无中英文切换（只有部分英文副标题） | 海外客户（巴斯夫、沙特阿美等）无法阅读 | 英文站 P1 |
| D15 | 无站内搜索 | 内容量大（产品 16 面板 + 标准 30 条 + 软著 28 条）却无法检索 | 站内搜索（K-05） |
