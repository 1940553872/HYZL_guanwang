## 1. 编制说明与映射规则

> 《F 类团队职责工作驱动板》编制说明原文仍未提供。以下映射规则按 5W2H、SMART、SAO 通行定义编制，属**假设版本**；收到原文后只需调整字段名与顺序，内容不受影响。

### 1.1 字段映射

| 驱动板字段 | 映射规则 |
|---|---|
| **What** | 岗位职责事项与交付物（取自对应 K 文档任务 1—6） |
| **Why** | 关联业务目标 G1—G5 或质量目标 Q1—Q6（§1.2），每条职责至少关联 1 个 |
| **Who** | R 负责；C 协作；I 知会（RACI） |
| **When** | 里程碑周次（T0 + Wn，README §4）与截止闸门 |
| **Where** | 工作环境 / 系统 |
| **How** | 方法、流程、规范（引用 K 文档章节） |
| **How much** | 工作量（人日）+ 衡量指标目标值 |
| **SAO 职责描述** | "主体 S（岗位）— 动作 A（可验证动词）— 对象 O（交付物 / 系统对象）"，编号 `K-xx-Rn` |
| **SMART 衡量口径** | S：对象明确；M：指标 + 公式 + 数据来源；A：可达成依据；R：关联 G / Q；T：截止节点 |
| **输入 / 输出** | 输入 = 开工所需上游交付物；输出 = 交给下游的交付物（§3） |
| **前置 / 后置条件** | 前置 = 允许开工的就绪状态；后置 = 完成后必须达到的状态与交接动作 |
| **系统 / 软硬件工具** | 平台、软件、硬件、测试设备 |

### 1.2 目标编号
- **G1** 有效预约演示线索 ≥ 30 条 / 月（上线 90 天内）；**G2** 资料下载 ≥ 100 次 / 月（资料上线后）；**G3** 首页跳出率 ≤ 55%；**G4** 首页移动 LCP ≤ 2.5 s（P75）；**G5** 搜索引擎收录 ≥ 150 个 URL
- **Q1** 设计还原度 ≥ 95%；**Q2** WCAG 2.1 AA；**Q3** 零阻断 / 严重缺陷上线；**Q4** 页面可用性 99.9%；**Q5** 安全高危 = 0；**Q6** 内容准确性 100%（勘误关闭、口径齐全、授权与证书有效）
