## 1. 迁移原则
1. **原文不直接搬运**：官网补录文字作为"事实来源"，所有上线文案按 02 §7 重写，事实（数字、编号、日期）逐项对照原图。
2. **OCR 文字不上线**：`图片文字.txt` 中的文字只作检索参考；标"〔待核〕"的条目一律不用。
3. **先勘误后录入**：01 §5 的 30 条勘误在内容录入前关闭。
4. **一条事实一个来源**：产品名称、标准条目、证书等在内容管理后台只录入一次，页面引用同一条数据（避免现网"17 项 / 18 项"、"iCE / iCTE"这类不一致）。
5. **历史内容归档而不删除**：2018—2020 年新闻与早期案例迁入"历史动态 / 历史案例"，不进首页。

## 4. 素材迁移

逐项清单：[assets/asset-mapping.csv](./assets/asset-mapping.csv)（字段：素材路径、尺寸、大小、现网用途、新站页面、新站用途、处理方式、备注 / 风险）。

### 4.1 处理规范

| 处理方式 | 规范 |
|---|---|
| 直接使用（加水印） | 证书类：裁白边 → 统一 3:4 缩略图（480×640）+ 原图灯箱（长边 ≤ 1600）；右下角半透明水印"华云智联 · 仅用于官网展示" |
| 裁切调色 | 按 16:9 / 4:3 裁切；统一调色（降饱和 15%、色温略冷、暗部压深）；分辨率不足 1200px 宽的只作缩略图 |
| 脱敏核查后使用 | 遮挡客户名称、人名、真实生产数据、坐标；"崔木智慧矿区综合驾驶舱"（`engines.jpg`）含欢迎标语与人名，须客户书面授权 |
| 重绘为 SVG | 架构图按 K-01 图形规范重绘（线宽 1.5px、华云蓝 / 灰阶 / 华云橙），原图作为内容依据 |
| 替换为矢量 Logo | 合作伙伴 Logo 向对方索取或从官方品牌页下载矢量版，统一单色显示，悬停还原彩色 |
| 停用 | 不进入新站，保留在素材库 |

### 4.2 命名与存储
- 新站素材路径：`/media/<栏目>/<内容 slug>/<用途>-<序号>.<ext>`，例如 `/media/products/imes/screenshot-01.avif`。
- 构建时由图片服务输出 AVIF / WebP / JPEG 三种格式与 1x / 2x 尺寸（K-04 §3）。
- 原始素材留在仓库 `素材库/`，不直接部署。
