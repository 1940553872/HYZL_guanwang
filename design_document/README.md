## 5. 统一约定
- **页面编号**：`P-xx`，定义见 [K-02 §2](./K-02-ux-ia-usability.md)，所有文档统一引用。
- **需求编号**：`REQ-<模块>-<序号>`；**缺陷级别**：阻断 / 严重 / 一般 / 建议（K-03、K-06 共用）。
- **断点**：`xs <640`、`sm ≥640`、`md ≥768`、`lg ≥1024`、`xl ≥1280`、`2xl ≥1440`（设计基准 1440 / 390）。
- **素材引用**：一律写素材库相对路径（如 `素材库/images/product/v2/swarm.jpg`），与 asset-mapping.csv 一致。
- **【待确认】**：评审时逐条关闭。
